Course proposal form

Aga Khan University

Power Apps · Power Automate · SharePoint · PDF generation

Problem

Creating and changing courses needed a consistent process with approvals, a record of every change, and no duplicate courses.

What I built

  • Faculty create new courses and request minor or major modifications to existing ones.
  • Users from one entity can copy a course from another entity.
  • Editing a course creates a new version of the form, so the full version history is kept.
  • The app creates a PDF and returns it filled in.
  • Admins approve or reject forms, which updates the PDF with the approved date.
  • A separate admin can add a course to the brochure from the app, which updates the PDF too.
  • Duplicate courses for the same entity are blocked.
  • A built-in dashboard shows basic KPIs, and a settings screen is used to configure features.

Result

Filled PDFs are produced automatically and kept up to date through approval and brochure updates. Every change is tracked in version history, and duplicate courses are prevented.
